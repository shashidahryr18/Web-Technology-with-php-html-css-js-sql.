# Web Technology & Full-Stack Development

Welcome to the **Web Technology** repository! This repository contains a comprehensive collection of practical lab experiments, coursework exercises, and project files covering foundational to advanced topics in full-stack web development.

---

## 🛠️ Tech Stack & Languages

* **Frontend:** HTML5, CSS3, JavaScript (ES6+), jQuery
* **Backend:** PHP
* **Database:** MySQL / SQL

---

## 📁 Repository Overview & Topics Covered

### 1. HTML & JavaScript Essentials
* **DOM Manipulation & Events:** Custom button actions, interactive styling, and event handling (`buttonjs.html`, `Name_Buttons.html`, `welcome guest.html`).
* **JavaScript Functions & ES6 Features:** Arrow functions (`Arrow function.html`), array traversal (`Travel in array.html`, `Loop for array.html`), string processing (`Vowel funnction.html`), and max-value calculations (`find max from array.html`).
* **UI & Styling:** CSS Animations (`Animation.html`), UI components (`neon-loader-animation.html`), dynamic highlights (`names using higlight colours.html`), and forms (`student registration form.html`).
* **jQuery:** DOM traversal and dynamic interaction using jQuery library files (`Jquery.html`, `jquery.js`).

### 2. PHP Fundamentals & Logic
* **Basic Syntax & Structure:** Variable definitions, constants, and magic variables (`variables.php`, `constant_variables.php`, `magic_variable.php`).
* **Control Structures:** Loops, conditions, and mathematical routines (`Conditional & Looping.php`, `Amstrong number.php`, `Fibonanci series.php`, `sum of Digits.php`, `display Reverse of it.php`, `of n! factorial of a number n.php`).
* **Arrays & Tables:** Indexed, associative, and multi-dimensional arrays, rendered into structured HTML tables (`Indexed_array.php`, `Associative_array.php`, `Multidimensional_arrays.php`, `Array_in_tables.php`).
* **Patterns & Logic Building:** Matrix and character sequence generation (`Print pattern 12345.php`, `Print pattern ABCDE.php`).

### 3. PHP File System & Utilities
* **File Handling:** Reading files, handling file uploads, and includes/requires (`fileread.php`, `fileuplod.php`, `filemanagement_include.php`, `require.php`).
* **Strings & Utility Scripts:** String functions, dynamic greetings, background color switchers, and password generation (`string_functions.php`, `GreetingMessage.php`, `Generate passaword.php`, `backgroundcolor.php`).

### 4. Database Integration & MySQLi
* **Database Connection & Setup:** Establishing connections to MySQL server and setting up databases (`data-base-connection.php`, `Databases_setup.php`, `Showdatabase.php`).
* **Authentication & User Management:** User creation routines, database credentials management, and login implementations (`Creating user name&passwd for database.php`, `loginpage using htmland.php`, `loginpage.php`).
* **Lab Exercises:** Sequential experiment files covering database connectivity and query execution (`Lab 13 part 2.php`, `Lab 14_part_01.php`, `squli.php`).
